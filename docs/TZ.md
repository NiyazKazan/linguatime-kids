LinguaTime Kids - Техническое задание MVP

1. Название проекта
LinguaTime Kids (рабочее название)

2. Цель проекта
Создать Android-приложение для детей и родителей, где ребёнок изучает английский язык с ИИ-агентом, получает баллы и обменивает их на разрешённое экранное время.

3. Платформа
Android, одно приложение с двумя режимами: родитель и ребёнок.

4. Целевая возрастная группа MVP
8–14 лет.

5. Начальный уровень английского
Pre-A1 / A1, включая старт с нуля.

6. Формат обучения
Текст + аудио.

7. Роль родителя
- регистрация;
- создание профиля ребёнка;
- привязка устройства;
- настройка лимитов;
- просмотр прогресса;
- одобрение запросов экранного времени.

8. Роль ребёнка
- вход в детский режим;
- прохождение теста уровня;
- обучение;
- получение баллов;
- запрос экранного времени.

9. Баллы
Баллы начисляются за:
- завершение урока;
- правильные ответы;
- ежедневные задания;
- серию дней.

Баллы хранятся на сервере.

10. Экранное время
Ребёнок может обменивать баллы на:
- минуты использования телефона;
- минуты игр;
- минуты YouTube;
- минуты мессенджеров;
- другие разрешённые приложения.

11. Ограничение Android
Приложение не разблокирует системный экран Android.
MVP использует app-level parental control, запросы времени и родительское одобрение.

12. ИИ-агент
- проводит тест;
- подбирает задания;
- объясняет ошибки;
- ведёт учебные диалоги;
- адаптирует сложность.

ИИ работает только в безопасном учебном режиме.

13. Backend
Firebase:
- Authentication;
- Firestore;
- Cloud Functions;
- Cloud Messaging.

14. Безопасность
- родительский PIN;
- серверное начисление баллов;
- AI-ключи только на сервере;
- защита детских данных;
- журнал операций.

15. Что не входит в MVP
- iOS;
- реальная разблокировка телефона;
- полноценный системный parental control;
- голосовой ответ ребёнка;
- проверка произношения;
- офлайн-режим;
- социальные функции.

16. Этапы
1. ТЗ.
2. Дизайн.
3. Firebase.
4. Android-каркас.
5. Учебный модуль.
6. ИИ.
7. Баллы и время.
8. Тестирование.
9. Публикация.
